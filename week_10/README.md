Week 10 - HR Salary Calculator
A modular Python program that calculates employee monthly salaries, deductions, overtime pay, and tenure rewards.

Directory Structure
main.py: Main entry point to coordinate application workflow.
employee.py: Handles input collection for employee details.
salary.py: Performs gross salary, overtime, bonus, EPF, SOCSO, and net salary calculations.
report.py: Displays the formatted final salary report.
