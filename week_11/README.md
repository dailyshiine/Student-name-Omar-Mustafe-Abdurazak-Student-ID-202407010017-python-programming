# Week 11 - Tutorial 11: Computer Lab Access System

A modular Python application for City University's Computer Lab Access System.

## Modules
- `student.py` — collects student input (name, ID, and access conditions)
- `access.py` — checks access using conditional statements and the `and` operator, and returns the reason
- `display.py` — displays the final access result
- `main.py` — integrates all modules

## How to Run
```
python main.py
```
